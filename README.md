# Inlämmning 1 för scripting

## Beskrivning

Detta PowerShell-skript skapar en enkel mappstruktur baserat på ett namn som användaren skriver in.

Skriptet skapar en huvudmapp och tre undermappar:

- logs
- scripts
- temp

I mappen `logs` skapas även en loggfil med dagens datum. Loggfilen innehåller information om när den skapades.

## Lärdommar 
Kul uppgift som kändes väldigt givande för att få en grund i scripting.
