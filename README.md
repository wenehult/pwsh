# Inlämmning 1 för scripting

## Beskrivning

Skriptet skapar en huvudmapp och tre undermappar:
Huvudmappen:
-Huvudmappen får namnet som användaren skriver in när den får frågan efter den kört skriptet. 

Undermapparna
- logs
- scripts
- temp

I mappen logs skapas även en loggfil med dagens datum. Loggfilen innehåller även information om när den skapades.


## Hur man kör skriptet

1. Öppna PowerShell.
2. Gå till mappen där skriptet finns.
3. Kör .ps1 filen genom att skriva in hela namnet och tryck enter.

Alternativt kör man den i vs code genom att gå in i filen och trycka play.
